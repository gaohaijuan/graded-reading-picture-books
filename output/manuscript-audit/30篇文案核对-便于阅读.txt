现用1《你好，我是小石头》；第1册PDF 3–8页
P1 你好！ / 我是小石头。
P2 我的名字 / 叫小石头。
P3 你的名字 / 是什么呢？
P4 我五岁了。 / 你几岁呢？
P5 我上大班了。
P6 你也是吗？
可斟酌：P1–2「我是小石头」「我的名字叫小石头」
两页表达接近，互动主要靠读者口头回答；如果按故事评价，会显得重复。
建议方向：先确认它的定位是开场互动篇；不必为了补情节硬改。

现用2《我的花》；第1册PDF 10–15页
P1 我的小花。
P2 我的花 / 有好多片。
P3 一片两片三四片，
P4 五片六片七八片，
P5 九片十片十一片，
P6 飞入草丛都不见。
建议修改：P2「我的花，有好多片」；P6「飞入草丛都不见」
“片”缺少被数的对象；从数数突然跳到全部飞走，正文没有交代风或花瓣脱落。诗歌可以省略，但初读者需要更多画面推断。
建议方向：确认是花瓣计数诗；文字或分镜至少一处明确对象和风起，避免把花瓣误读为整朵花。

现用3《我家有几口人？》；第1册PDF 17–23页
P1 我家有几口人？ / 我来数一数。
P2 这是爸爸。
P3 这是妈妈。
P4 我数好了！ / 一共有两口人。
P5 咦？ / 我把谁忘了？
P6 是我呀！ / 还要加上我。
P7 我家有三口人。 / 我们都在家！
可保留：P4「一共有两口人」→P6「还要加上我」→P7「我家有三口人」
先漏数自己是有意设置的笑点，不能只截取P4判为人数错误；全文完成了纠正。
建议方向：整段连读并保留纠错结尾；人数随家庭设置变化。

现用4《我的小手》；第1册PDF 25–30页
P1 我有两只小手。
P2 小手开， / 小花来。
P3 小手关， / 小花去。
P4 小花，小花， / 你不来了吗？
P5 小手开， / 小花回来了！
P6 我的小手， / 是小花的家！
建议修改：P2「小手开，小花来」；P3「小手关，小花去」
没有写明手掌张开像花，容易读成另有一朵花来回移动；“小手关”也偏为押句式而造句。
建议方向：先明确这是手势游戏，再决定文字保留多少诗性省略。
